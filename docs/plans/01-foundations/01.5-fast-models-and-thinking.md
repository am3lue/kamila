# 01.5 — Fast Models & Thinking Display

## Objective

Give Kamila a fast, resilient model setup: two named Ollama models — **kamila1** (online, `gpt-oss:120b-cloud`) and **kamila2** (offline, local `qwen3:8b`) — with automatic online→offline fallback on error/timeout, and surface model "thinking" (reasoning) in the Node TUI as a click-to-expand block that is never mixed into answers, history, or tool-call parsing.

## Background / Current State

- `deepseek-v3.2:cloud` was **retired** by the provider (`"retired at 2026-07-15"`); all current DeepSeek cloud tags return `"requires a subscription"` — DeepSeek is effectively unusable.
- `gpt-oss:120b-cloud` works and emits reasoning in `message.thinking` on `/api/chat`.
- Prior design had a single `kamila:latest` model (from `config/Modelfile`, `FROM gpt-oss:120b-cloud`) and a `qwen2.5-coder:0.5b` `:default`/`:quick` fallback. Agent stream loop duplicated the user prompt into context on every iteration.

## Design

- **Dual named models**: `config/Modelfile.online` → `kamila1` (online default); `config/Modelfile.offline` → `kamila2` (offline fallback). `kamila:latest` + `config/Modelfile` retained as backup, buildable but unused by default.
- **Router defaults** (`DEFAULT_MODELS`): `kamila1` chat/code (priority 1), `kamila2` chat/code (priority 2), `qwen2.5-coder:0.5b` quick (priority 1). The `:default` fallback entry is removed. `validate_model` accepts the built-ins.
- **Streaming items**: `OllamaInterface.StreamItem(text, is_thinking)`; `query_ollama_chat_stream` emits thinking chunks from `message.thinking` tagged `is_thinking=true`; `query_router_chat_stream` relays items and fills a caller-supplied `model_ref` with the model that actually answered.
- **Timeout**: curl streams use `--max-time $CURL_MAX_TIME` (default 15s, env `KAMILA_CURL_MAX_TIME`) so a hung online model falls back fast.
- **Thinking routing**: bridge relays thinking as stream `kind="thinking"` events; it is never appended to `full_response`, history, or `Agent.parse_response` input. `stream_end` carries `"model"` = answering model name.
- **TUI**: `onThinking` callback routes chunks to a live `🧠 Thinking… (click to expand)` line; clicking the line toggles expand/collapse, other lines still copy.
- **Agent loop fix**: history seeded once with `("User", prompt)`; context built from history and capped by `max_history`; no duplicate prompt push on each iteration.

## Risks & Mitigations

- **Risk:** Online model hangs instead of erroring. **Mitigation:** `--max-time 15` (env-tunable) forces fallback.
- **Risk:** Thinking text inflates history / confuses tool parsing. **Mitigation:** thinking is never persisted or parsed; only content feeds history/`parse_response`.
- **Risk:** Shared curl payload temp file races between concurrent streams. **Mitigation:** unique `tempname()` per call.
