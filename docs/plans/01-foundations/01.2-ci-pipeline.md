# 01.2 — CI Pipeline

## Objective

Automatically run the test suite, lint checks, and a bridge smoke test on every push and pull request, so regressions are caught before they reach the user. Works locally and in a containerized environment identical to the Docker deployment.

## Current State

- No CI configuration exists (no `.github/workflows`, no pre-commit hooks).
- `bin/kamila --setup` runs `Pkg.instantiate()` + `npm install` + `ollama create` manually.
- The Dockerfile (`Dockerfile`) builds Arch Linux + Julia + Node but runs only `Pkg.instantiate()`/`Pkg.precompile()`, not tests.
- No lint configuration for Julia (`JuliaFormatter` / `JET.jl` / `Aqua.jl`) or Node (ESLint).

## Design

- **GitHub Actions** workflow matrix: (1) Julia unit/integration (the `01.1` runner, no network), (2) Node TUI lint + syntax, (3) full-stack smoke test that boots `bin/kamila --bridge` against a canned stdin script.
- **Containers:** use `julia:1.12` official image (matching `Dockerfile`'s pinned 1.12.x) instead of building Arch in CI; Arch specifics are only needed for the Docker image, not the test matrix.
- **Linting:** add `JuliaFormatter` (format check, not rewrite, in CI), `Aqua.jl` (ambiguity/unbound-args checks), and `JET.jl` (type-check) as dev dependencies. Add ESLint config for `tui/`.
- **Pre-commit:** optional `pre-commit` config that runs the fast local targets (`tools`, `agent`, `security`).
- **Badge:** status badge in `docs/README.md` pointing at the workflow.

## Risks & Mitigations

- **Risk:** CI flakiness from Ollama. **Mitigation:** the bridge job uses the `01.1` Ollama mock server, not a real model; a real-Ollama job is nightly-only and non-blocking.
- **Risk:** JuliaFormatter would rewrite lots of existing code. **Mitigation:** CI checks formatting but does not auto-rewrite; a separate `scripts/format.sh` is provided for the team to adopt.
- **Risk:** GitHub Actions minutes. **Mitigation:** caching `~/.julia`, `Pkg.instantiate` on the cached depot.

## Dependencies

- Depends on: `01.1-test-infra` (CI runs its runner).
- Blocks: everything that wants a "green on PR" guarantee.
