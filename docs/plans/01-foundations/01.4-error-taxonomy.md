# 01.4 — Error Taxonomy

## Objective

Replace the "everything is a string" error handling with a typed, categorized error model so tools, the bridge, and the TUI can react appropriately (retry vs. deny vs. user-fix vs. fatal). This is a prerequisite for reliable agent behavior: an agent can only recover from errors it can recognize.

## Current State

- `extract_error(e) = string(e)` (`src/ai/tools.jl:137`) — the "taxonomy" today. Every tool returns a plain `"Error: ..."` string.
- `execute_tool` wraps everything in `"Error executing tool 'X': $(extract_error(e))"` (`src/ai/tools.jl:849-852`).
- `ModelRouter.is_error_response(s)` (`src/ai/model_router.jl:165`) heuristically detects errors by string prefix (`"❌"`, `"error:"`, `"timeout"`, ...).
- Bridge `send_error` only carries a message + numeric code (`src/bridge.jl:35`), codes are ad-hoc (400/401/404/500/403).
- `read_file`/`write_file`/etc. each hand-roll their error strings.

## Design

- Define `struct KamilaError <: Exception` with fields: `category::Symbol`, `message::String`, `code::Int`, `retryable::Bool`, `details::Dict`.
- Categories: `:permission`, `:validation`, `:notfound`, `:timeout`, `:network`, `:external`, `:model`, `:internal`, `:unsupported`.
- Add `category`-aware helpers: `is_retryable(e)`, `http_status(e)` mapping categories → HTTP codes (permission→403, notfound→404, validation→400, internal→500, timeout→504).
- Tools throw `KamilaError` instead of returning strings; `execute_tool` catches and returns a string **plus** emits a structured log + structured `tool_result` payload for the bridge so the TUI can color/render by category.
- Extend bridge `send_error` and the `error` event to include `category` and `retryable`.
- Update `ModelRouter.is_error_response` to check category first, keep string-prefix as fallback.
- Keep backward compatibility: `string(e)` and the existing `"Error:"` prefixes still parseable by the current TUI during transition.

## Risks & Mitigations

- **Risk:** Widening the diff across all tools. **Mitigation:** keep string return format for tools during transition; only `execute_tool_structured` adds structure.
- **Risk:** Retry loops amplify damage. **Mitigation:** retries only for `:timeout`/`:network`/`:external`, capped at 2, and never for `:permission`/`:validation`.
